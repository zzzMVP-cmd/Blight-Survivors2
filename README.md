# Blight Survivors 2

[Blight Survivors](https://github.com/zzzMVP-cmd/Blight-Survivors) 的二作。原版代码无法继续改动且未工程化，本作彻底重做并采用模块化工程结构。

---

## 项目结构

```
Blight Survivors2/
├─ index.html            ← 只保留绘制层（canvas），按依赖顺序引用 js 文件（不合并）
├─ css/style.css         ← 全部样式
├─ js/
│  ├─ systems/           ← 所有游戏系统
│  │  ├─ heroes.js       ← 英雄数据定义
│  │  ├─ monsters.js     ← 怪物基础数值与绘制
│  │  ├─ monster-ai.js   ← 怪物行为（生成/移动/攻击/击退）
│  │  ├─ attack/          ← 所有攻击相关系统
│  │  │  ├─ weapon.js     ← 武器系统（剑状态机 + 剑气扇形效果）
│  │  │  ├─ attack.js     ← 各英雄攻击判定（战士扇形判定等）
│  │  │  ├─ crit.js       ← 暴击系统（概率补偿）
│  │  │  └─ augment.js    ← 增幅系统（力量/速度表现增幅）
│  │  ├─ upgrade.js      ← 升级强化系统（卡牌选择/等级/刷新）
│  │  ├─ exp-orbs.js     ← 经验球（掉落/吸引/拾取）
│  │  └─ wave.js         ← 波次管理（准备/间隔/清场提前/1.2倍递增）
│  ├─ menu.js            ← 开始页：英雄选择 + 开始按钮
│  ├─ hud.js             ← 游戏内 HUD（血条/等级/波次/经验条/武器栏/道具栏）
│  ├─ game.js            ← 游戏主循环（玩家移动/摄像机/绘制调度）
│  └─ main.js            ← 初始化入口（画布尺寸、构建开始页）
├─ electron/main.js      ← 桌面版窗口逻辑（Electron）
├─ assets/images/        ← 图片资源（warrior.png, weapon_warrior.png）
├─ package.json          ← 桌面版依赖与打包配置（electron-builder）
├─ pack.bat              ← 打包脚本（构建 NSIS 安装版 → release\ 目录）
├─ clean.bat             ← 清理脚本（删除 release\、packed\、dist\）
└─ README.md
```

## 当前进度

### 开始页（已完成）

- 顶部一排英雄选择框，当前仅「战士」一个英雄
- 底部「开始游戏」按钮，默认灰色禁用；选中某个英雄后变亮可用
- 视觉沿用原作的深色背景 + 金色渐变标题风格

### 游戏玩法（进行中）

- 英雄始终在屏幕中心，WASD 移动，摄像机跟随
- 左上角血条（当前/总血量）+ 等级（lv.x）+ 波次信息
- 顶部全屏绿色经验条
- 左下角武器栏，右侧道具栏（暂空）
- 怪物（史莱姆）：朝玩家移动，碰撞造成伤害并自身击退
- 波次系统：3s 准备 → 第一波，间隔 15s，清场后 1s 提前下一波
- 每波数量/血量/伤害为上波 1.2 倍（四舍五入）
- 怪物体积随波次线性增大（每波 +3%，第 50 波封顶后不再增大；血量仍持续 1.2 倍增长）
- 怪物护盾：每 50 波基础护盾 +1，且整体每波 ×1.2（`floor(波数/50) × 1.2^波数`），第 50 波起生效
  - 怪物外层显示白偏色护盾环，下部缺口处显示护盾值，护盾越少越透明
  - 锐器伤在暴击后、穿透前先除以怪物护盾值；伤害优先扣护盾，溢出才扣血
  - 穿透判定：阈值为「(怪物血量 + 护盾) / 体积」，体积 = πr³（r 为怪物半径）
- 升级所需经验：每级为上阶的 1.4 倍（四舍五入）；**每次升级血量与护盾直接加满**
- 英雄护盾：每 50 级基础护盾 +10，可在「护盾强化」卡（铜/银/金/炫彩 ×1.2/1.4/1.8/2.6）继续成长
  - 血条外部套一圈蓝色护盾条，血条下方显示「护盾值 / 最大护盾值」
  - 受击时伤害先除以护盾值，优先扣护盾；恢复时先回血，血满后再回护盾
- 怪物无攻击间隔，碰撞节奏由玩家 0.5s 无敌帧控制
- 怪物分离力：互相重叠的怪物会被沿连线推开（分离速度 150px/s），不再全部堆叠在英雄身上
- 升级选卡：一次连升多级时排队，选完一张卡后若还有待选次数会继续弹出，直到全部选完
- 武器转向：仅在攻击间隔（`cooldown`）内缓慢转向移动方向；不在攻击间隔内（`idle`）直接对准移动方向
- 伤害数字：最多同时显示数值最高的 100 条（在 `add()` 时即裁剪，超出时丢弃较小数值或替换最小值）
- 渲染上限：同屏最多渲染距离英雄最近的 100 只怪物、数值最高的 100 条伤害数字、距离英雄最近的 100 个经验球（仅限制绘制，逻辑照常计算）
- 怪物渲染间距（逐圈筛选）：第 n 圈的最小中心距 = (r1 + r2) / n，第一圈系数为 1（刚好贴边）
  - 每圈筛完若不足 100 只，就对上一圈未入选的怪物再用 1/2、1/3… 的系数再筛一圈，直到凑满 100 只或没有剩余怪物
  - 怪物总数不足 100 只时也会逐圈筛完，最终全部渲染，不再出现「少了几只就突然全部重叠渲染」
- 怪物护盾为 0 时不绘制护盾环与护盾数值

## 如何运行

### 网页版（开发调试）
直接用浏览器打开 `index.html` 即可（纯静态，无需服务器）。

### 桌面版（安装 exe）
- **运行**：双击 `release\BlightSurvivors2_Setup_v0.4.2.exe` 安装，安装后从桌面快捷方式或开始菜单启动（装到当前用户目录，不需要管理员权限）。
- **为什么改成安装版**：便携单文件 exe 每次启动都要把约 268MB 的 Electron 运行时解压到系统临时目录，实测启动约 8.5~8.8s；安装版文件常驻硬盘，启动约 1~2s。
- **可缩放窗口**：窗口支持自由缩放，最小尺寸 640×480。
- **卸载**：设置 → 应用 → 「Blight Survivors 2」→ 卸载（不会删除游戏数据）。
- **构建**：先 `npm install` 安装依赖，再运行 `pack.bat`（或 `npm run dist`），完成后安装包位于 `release\` 目录；免安装的文件夹版位于 `release\win-unpacked\`。
