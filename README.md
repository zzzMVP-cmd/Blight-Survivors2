# Blight Survivors 2

[Blight Survivors](https://github.com/zzzMVP-cmd/Blight-Survivors) 的二作。

原作代码无法继续改动且未工程化，本作彻底重做，采用模块化工程结构（HTML/CSS/原生 JS + Electron 桌面封装）。

---

## 玩法

类《吸血鬼幸存者》的俯视角生存游戏：操控英雄，在不断增强的怪物波次中活下去。

### 操作

| 操作 | 按键 |
|---|---|
| 移动 | `W` `A` `S` `D` |
| 攻击 | 自动（武器按自身攻击间隔挥砍） |
| 蓄力 | 按住鼠标左键，松开结算 |
| 暂停 / 撤离 | `ESC` |

### 核心机制

- **视角**：英雄始终在屏幕中心，摄像机跟随移动。
- **英雄**：当前仅「战士」一名，武器为「破阵斩」（扇形范围锐器伤，攻击间隔 2s）。
- **怪物**：史莱姆，朝英雄移动，碰撞造成伤害并自身击退；英雄有 0.5s 无敌帧。
- **波次**：3s 准备 → 第一波，之后每 15s 一波；提前清场则 1s 后进入下一波。
  - 每波数量、血量、伤害均为上波的 1.2 倍。
  - 同屏存活上限 700 只，超出部分排队补刷，不丢弃（详见 [CHANGELOG](CHANGELOG.md)）。
- **成长**：击杀掉落经验球，拾取升级，每级所需经验为上阶的 1.4 倍；升级时血量与护盾直接加满。
- **升级选卡**：每次升级三选一（可刷新），卡牌分铜 / 银 / 金 / 炫彩四档，档位决定倍率强弱。

### 系统一览

| 系统 | 说明 |
|---|---|
| 攻击 | 武器状态机、连续攻击、蓄力合并结算 |
| 暴击 | 概率补偿机制，伤害随暴击等级对数增长 |
| 穿透 | 锐器伤按「(最大血量 + 当前护盾) / 体积」判定，越过阈值造成穿透伤害 |
| 护盾 | 英雄受击时伤害先除以护盾值，再优先扣护盾 |
| 增幅 | 力量 / 速度表现增幅，分武器专属与全体两类 |
| 升级强化 | 角色强化、增幅强化、恢复、吸收范围、刷新次数、卡牌数量等 |

## 运行

- **安装**：双击 `release\BlightSurvivors2_Setup_v0.5.2.exe`，装到当前用户目录，不需要管理员权限。
- **启动**：桌面快捷方式或开始菜单。
- **卸载**：设置 → 应用 → 「Blight Survivors 2」。
- **窗口**：支持自由缩放，最小 640×480。

## 项目结构

```
Blight Survivors2/
├─ css/style.css              ← 全部样式
├─ js/
│  ├─ systems/
│  │  ├─ heroes.js            ← 英雄数据定义
│  │  ├─ monsters.js          ← 怪物基础数值与绘制
│  │  ├─ monster-ai.js        ← 怪物行为（生成 / 移动 / 攻击 / 击退 / 分离）
│  │  ├─ attack/
│  │  │  ├─ weapon.js         ← 武器系统（剑状态机 + 连续攻击 + 剑气扇形效果）
│  │  │  ├─ charge.js         ← 蓄力系统（蓄力条绘制 + 多次攻击合并结算）
│  │  │  ├─ attack.js         ← 攻击判定（战士扇形判定等）
│  │  │  ├─ crit.js           ← 暴击系统（概率补偿）
│  │  │  └─ augment.js        ← 增幅系统（力量 / 速度表现增幅）
│  │  ├─ upgrade.js           ← 升级强化系统（卡牌选择 / 等级 / 刷新）
│  │  ├─ exp-orbs.js          ← 经验球（掉落 / 吸引 / 拾取）
│  │  ├─ shield.js            ← 护盾系统（英雄护盾结算与成长）
│  │  ├─ recovery.js          ← 恢复系统（每秒回血）
│  │  └─ wave.js              ← 波次管理（间隔 / 递增 / 同屏上限 + 排队补刷）
│  ├─ menu.js                 ← 开始页（英雄选择 + 开始按钮）
│  ├─ hud.js                  ← 游戏内 HUD（血条 / 等级 / 波次 / 经验条 / 武器栏 / 道具栏）
│  ├─ game.js                 ← 游戏主循环（玩家移动 / 摄像机 / 绘制调度）
│  └─ main.js                 ← 初始化入口（画布尺寸、构建开始页）
├─ electron/main.js           ← 桌面版窗口逻辑
├─ assets/images/             ← 图片资源
├─ package.json               ← 桌面版依赖与 electron-builder 配置
├─ pack.bat                   ← 打包脚本（构建 NSIS 安装版 → release\）
├─ clean.bat                  ← 清理脚本（删除 release\、packed\、dist\）
├─ CHANGELOG.md               ← 完整更新日志
└─ README.md
```

## 构建桌面版

```bash
npm install
npm run dist      # 或直接双击 pack.bat
```

产物：

- `release\BlightSurvivors2_Setup_v0.5.2.exe` —— NSIS 安装版
- `release\win-unpacked\` —— 免安装文件夹版

清理临时产物：双击 `clean.bat`。
